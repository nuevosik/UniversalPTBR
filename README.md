# Tradução Universal (PT-BR)

Tradução para português do Brasil de mods de RimWorld (1.6 e 1.7): série **Vanilla Expanded** e mods populares como *The Dead Man's Switch*, *World Domination 2.0*, *Alpha Animals*, *Vehicle Framework* e outros.

## Instalação

- **Steam Workshop:** [Tradução Universal (PT-BR)](https://steamcommunity.com/sharedfiles/filedetails/?id=3643091941)
- **Manual:** baixe a [última release](https://github.com/nuevosik/UniversalPTBR/releases/latest) e extraia em `RimWorld/Mods/`.

## Contribuindo

Encontrou um erro ou um texto em inglês? Abra uma [issue](https://github.com/nuevosik/UniversalPTBR/issues) informando o mod e o texto.

Antes de enviar alterações, rode:

```bash
python3 tools/lint.py
```
